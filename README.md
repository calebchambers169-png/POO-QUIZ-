# GI & Hepatobiliary Clinical Case Studies

An interactive, self-contained study tool with **200 application-based clinical vignettes** covering gastrointestinal and hepatobiliary pathophysiology. Built for exam prep — open one HTML file in any browser, no install required.

Content spans GI physiology, gastric acid secretion, digestion & absorption, and disorders of the esophagus, stomach, intestine, liver, gallbladder, and pancreas (based on coursework from Chapters 36–38).

## Features

- **200 case-study questions** — patient scenarios and applied reasoning rather than rote recall (e.g. "bird's beak" achalasia, Murphy sign, the 4 F's of gallstones, AST/ALT vs ALP/GGT patterns, pre-/intra-/post-hepatic jaundice, Crohn's vs ulcerative colitis).
- **Rationale for every question** — each answer includes an explanation so you learn while you test.
- **Topic filtering** — drill a single system or mix everything together.
- **Flexible sessions** — choose 10, 25, 50, or all questions; shuffle or go in order.
- **Two feedback modes** — instant feedback after each question, or score-only at the end.
- **Progress tracking** — live score, progress bar, and a per-topic breakdown at the end.
- **Review missed** — re-drill only the questions you got wrong.
- **Keyboard shortcuts** — answer with `1`–`4` or `A`–`D`, advance with `Enter` / `→`.
- **Answer shuffling** — option order is randomized each session so you can't memorize positions.
- Fully responsive, works offline, and respects reduced-motion preferences.

## Usage

1. Download `GI_Hepatobiliary_CaseStudies.html`.
2. Open it in any modern web browser (double-click, or drag it into a browser window).
3. Pick your topics, session length, and feedback mode, then click **Start session**.

That's it — there's no build step, server, or dependencies. The entire question bank is embedded in the single HTML file.

## Tech

- Single self-contained HTML file (HTML + CSS + vanilla JavaScript).
- No frameworks, no external requests, no browser-storage dependencies — runs fully offline.
